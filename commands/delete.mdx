---
title: "ink delete: Permanently Remove a Saved Note by Its ID"
sidebarTitle: "Delete"
description: "ink delete removes a note after a single-keypress y/n confirmation. Press y to confirm deletion or any other key to cancel without changes."
---

`ink delete` removes a note from the database by its integer ID. Before performing the deletion, it always displays an interactive confirmation prompt so that accidental deletions are avoided. The note is only fetched and the prompt only shown if the given ID exists — a non-existent ID exits immediately with an error.

## Synopsis

```bash
ink delete <note_id>
```

## Arguments

<ParamField path="note_id" type="integer" required>
  The integer ID of the note to delete. Use `ink lst` to list all available notes and their IDs.
</ParamField>

## Confirmation Prompt

After locating the note, Ink Notes asks for explicit confirmation before proceeding:

```
Do you want to delete this note? (y/n):
```

The prompt reads a single keypress without requiring Enter:

- Pressing **`y`** or **`Y`** immediately deletes the note and prints a success message.
- Pressing **any other key** cancels the operation and prints a cancellation notice.

## Examples

```bash
ink delete 5
# Do you want to delete this note? (y/n): y
# ✓ Note deleted.

ink delete 5
# Do you want to delete this note? (y/n): n
# ⚠ Deletion cancelled.
```

## Error Handling

If no note exists with the supplied ID, Ink Notes prints the following message and exits — the confirmation prompt is **not** shown:

```
✗ Note not found.
```

<Warning>
  Deletions are **permanent**. Once a note is deleted there is no undo, no recycle bin, and no recovery path. Always double-check the note ID with `ink lst` or `ink view <id>` before confirming a deletion.
</Warning>
