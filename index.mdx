Ink Notes is a modern command-line application for capturing and organizing notes without leaving your terminal. Built with Python, it combines [Click](https://click.palletsprojects.com/) for a clean command interface, [SQLAlchemy](https://www.sqlalchemy.org/) for durable SQLite storage, and [Rich](https://github.com/Textualize/rich) for a colorful, readable output experience.

## What Ink Notes Does

Ink Notes stores notes in a local SQLite database and exposes them through six focused commands. Every note has a title, body content, optional tags, and timestamps that are managed automatically.

## Get Running in Seconds

<Steps>
  <Step title="Install Ink Notes">
    ```bash
    pip install ink-notes
    ```
  </Step>
  <Step title="Create your first note">
    ```bash
    ink add "Meeting recap" --content "Discussed Q3 roadmap" --tags "work,meetings"
    ```
  </Step>
  <Step title="List and search your notes">
    ```bash
    ink lst
    ink search "roadmap"
    ```
  </Step>
</Steps>

<Note>
  Ink Notes stores all data in a local `note.db` SQLite file — no account, no network, no external service required.
</Note>
