This page walks through every core command with real terminal examples so you can be productive with Ink Notes within minutes. By the end you will have created, listed, viewed, searched, updated, and deleted notes entirely from the terminal — no GUI, no browser, no configuration files required.

<Steps>
  <Step title="Install Ink Notes">
    If you have not already installed Ink Notes, grab it from PyPI:

    ```bash
    pip install ink-notes
    ```

    Once the command completes, the `ink` entry point is available in your terminal. Run `ink --help` at any time to see the list of available commands.
  </Step>

  <Step title="Create your first note">
    Use `ink add` followed by a title to create a new note. Pass `--content` to supply the body inline and `--tags` to attach a comma-separated list of tags:

    ```bash
    ink add "Python tips" --content "Use list comprehensions for clarity" --tags "python,tips"
    ```

    If you omit `--content`, Ink Notes will prompt you to enter the content interactively before saving. Tags are optional; when provided they are split on commas and stored as a JSON array.

    **Output:**
    ```
    ✓ Note 'Python tips' added with ID 1.
    ```
  </Step>

  <Step title="Add a second note">
    Create another note so you have something to list and search:

    ```bash
    ink add "Terminal workflow" --content "tmux + vim is a powerful combo" --tags "terminal,productivity"
    ```

    **Output:**
    ```
    ✓ Note 'Terminal workflow' added with ID 2.
    ```
  </Step>

  <Step title="List all notes">
    Display every note in the database with:

    ```bash
    ink lst
    ```

    Ink Notes renders a Rich-formatted table with four columns — **ID**, **Title**, **Tags**, and **Created** — sorted by creation date in descending order so your most recent notes appear first.
  </Step>

  <Step title="View a note by ID">
    To read the full content of a specific note, pass its ID to `ink view`:

    ```bash
    ink view 1
    ```

    Ink Notes renders a Rich panel displaying the note's **title**, **full content**, **created** and **updated** timestamps, and any **tags** attached to it. If the ID does not exist in the database, the command prints an error message instead.
  </Step>

  <Step title="Search your notes">
    Find notes that contain a keyword anywhere in their title, content body, or tags:

    ```bash
    ink search "python"
    ```

    The search is case-insensitive. Ink Notes scans all three fields — title, content, and tags — and displays every matching note using `show_search_results`, which highlights the matched keyword in the output. Notes that do not match the keyword are excluded.
  </Step>

  <Step title="Update a note">
    Modify one or more fields of an existing note by passing only the flags you want to change. Here we add an extra tag to note 1:

    ```bash
    ink update 1 --tags "python,tips,best-practices"
    ```

    Any field you do not pass (`--title`, `--content`) remains unchanged in the database.

    **Output:**
    ```
    ✓ Note '1' updated!
    ```
  </Step>

  <Step title="Delete a note">
    Remove a note by its ID. Ink Notes will ask for confirmation before deleting:

    ```bash
    ink delete 2
    ```

    **Confirmation prompt:**
    ```
    Do you want to delete this note? (y/n):
    ```

    Press `y` to confirm and permanently delete the note:
    ```
    ✓ Note deleted.
    ```

    Press any other key to cancel:
    ```
    ⚠ Deletion cancelled.
    ```
  </Step>
</Steps>
